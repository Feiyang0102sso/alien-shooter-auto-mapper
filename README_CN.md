# Auto Mapper v2.0.0

[English](README.md) | **中文**

Auto Mapper 是一款 Alien Shooter 地图自动铺设工具。你在画布上画墙、摆装饰、刷箱子和尸体，它负责把这些换算成游戏 `.map` 文件里的对象，并交给地图编辑器人工校验和细化。

## 功能

- **墙体**：用折线、直线、矩形在网格上画墙，自动铺设墙壁、门、地板和天花板。
- **曲线墙**（AS2 系列）：按住鼠标随手画，自动铺满山体、异形巢穴或悬崖；被围住的区域可自动铺上配套地板。
- **装饰套装**：AS2 系列 21 套、AS1 10 套现成的室内摆设，选好后在画布上点一下即可放下。
- **物资箱**（AS2 系列）：木箱、金属箱、异形蛋笔刷，一笔刷出一堆；可编辑掉落表，并保存为预设反复使用。
- **尸体血迹**（AS2 系列）：骨头堆、怪物尸体、士兵尸体、血滩笔刷，尸体周围自动撒血。
- **贴图预览**：指定游戏目录后，画布用游戏贴图显示装饰物、物资箱和尸体。
- **项目文件**：项目保存为 JSON，可随时导入继续编辑。
- **游戏版本**：支持 AS1 以及 AS2 系列（AS2、AS2R/C、AS2OE）的地图格式和墙体套装。
- **界面**：中文 / English 双语，常用操作都有快捷键。

## 重要警告

> [!WARNING]
> Auto Mapper 的算法不能保证在所有地图和布局下都完美无瑕。生成结果
> 始终只应作为起点，必须在地图编辑器中进行校验；最终以地图编辑器为准。

关于预览，还有几点限制：

- 只有在“贴图预览”（F9）窗口里指定游戏目录（含 `objects.res` 和 `Vid` 的文件夹）后，画布才用游戏贴图显示；
  未指定时只用绿色叉号标出物件位置。AS1 与 AS2 的目录分开设置。
- 贴图的前后遮挡只是近似，一切以地图编辑器中的实际显示为准。
- 墙体、门、地板不画贴图，只画线框。
- 物资箱的掉落表在每次生成地图时重新随机抽取，同一个项目两次生成的掉落不会完全一样。

## 推荐工作流

鉴于目前 Auto Mapper 还不具备编辑现有地图的能力，推荐按以下流程使用：

1. 先在 Auto Mapper 中创建或准备地图。
2. 优先完成并确认自动铺设部分没有问题，包括墙壁、门、地板和天花板。
3. 将生成的地图交给地图编辑器，确认自动布局正确后，再开始进一步的手动编辑。
4. 尤其是装饰部分，推荐每次调整一小部分，并在调整过程中持续回到地图编辑器验证。

## 快速上手

1. 解压发布包，运行 `AutoMapper.exe`。首次启动会让你选择界面语言。
2. 在左侧选择游戏（AS1 / AS2 系列及其版本），在右侧面板设置地图尺寸。切换 AS1 与 AS2 系列会新建项目。
3. 在左侧货架选择套装：墙壁套装、装饰套装，AS2 系列工程另有物资箱和尸体血迹。
4. 在画布上绘制，右侧面板调整当前工具的参数。F1 清空画布重新开始。
5. 生成地图（F4）得到 `.map` 文件；导出 JSON（F3）保存项目，方便以后继续编辑。

`AutoMapper.exe` 旁边的 `assets/` 文件夹存放装饰套装的库地图和预览图，请勿删除。

## 快捷键

| 分类 | 按键 | 功能 |
|---|---|---|
| 顶部功能 | F1 / F2 / F3 | 新建 / 导入 JSON / 导出 JSON |
| | F4 | 生成地图 |
| | F5 / F6 | 地板 / 天花板 开关 |
| | F7 / F8 | 门状态 / 随机方向 |
| | F9 | 贴图预览 |
| 套装导航 | Q / E | 上一个 / 下一个套装 |
| | - / + | 套装内上一个 / 下一个项目 |
| 工具 | 0 | 选择装饰物 |
| | 1 / 2 / 3 | 折线 / 直线 / 矩形 |
| | 4 | 橡皮擦 |
| | 5 | 手绘（曲线墙、物资箱、尸体血迹） |
| | Del | 删除选中的装饰物 |

程序内点击“快捷键”按钮也能查看这张表。焦点在输入框里时快捷键不生效。

## 从源码构建

需要 Visual Studio 2026（MSVC v145）和 Qt 6.11.1（Qt Base、Qt Image Formats，x64），不需要 CMake。

- 用 Visual Studio 打开 `vs/AutoMapper.sln` 直接构建；Qt 路径默认取自 `vs/qt.props`，可用环境变量 `QTDIR` 覆盖。
- 或运行 `builder.bat`：命令行构建 Release 并跑完全部测试。
- 构建完成后运行 `pack_release.bat` 打包发布目录和 zip。

输出在 `bin/x64/<配置>/`。
